# Intent

An alternative to the Docker neuron (`../neuron`): the Satori neuron as an app
that lives entirely in the browser — client-side, no server of our own to run.

- The Docker neuron stays; this is a second way to run a neuron, not a replacement.
- Owner's toolkit of choice for client-side apps: Arrow.js and DuckDB-WASM.
- "It'll do it all": the goal is full neuron behaviour in the browser.
- Named `satori` (lowercase) inside `Satori/` because prior names are taken and
  prior codebases are not to be changed.
